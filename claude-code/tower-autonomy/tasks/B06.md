**Status:** [ ] Partial — locally verified; awaiting commit, review, and merge

**Dependencies:** [B01](./B01.md), [B05](./B05.md)
**Dependency gate now:** [x] B01 and B05 are completed in the manifest

## Outcome

Use a single device lease and durable supervisor for ADB reconnect, game resume/relaunch, transient failures, bounded retry/backoff and crash recovery; preserve the verified account identity.

## Acceptance gate

Inject disconnect, stale frame, online-required action and process restart; recover the correct device and pending action or enter an explicit bounded blocked state without uncontrolled tapping.

## Current repository state

- [x] ADB capture and bot start/stop/pause lifecycle controls exist.
- [x] Local B06 slice: the fleet runner holds a durable supervisor checkpoint
  across process restarts. A guarded device writes a pending action before a
  click; a second click waits for a fresh changed frame and a verified account.
  B05's journal still owns purchase proof and refuses duplicate spending.
- [x] Local B06 slice: fleet and standalone entry points share one process
  lease for the ADB endpoint. Reconnect has a persisted attempt budget and
  exponential backoff. A configured `--game-package` is relaunched at most
  once per reconnect, then actions wait for fresh identity and screen proof.
- [x] Local B06 slice: unknown, stale, unreadable, online-required, wrong
  device/account, and exhausted retry states report an explicit blocked or
  quarantined reason and issue no tap.
- [ ] Still required: commit, review, and merge. Live ADB disconnect,
  relaunch, and account-bound tap recovery have not been performed.
