Game Speed is a workshop upgrade that raises the maximum speed your tower can run at. Higher game speed means more waves per minute of real time, which directly increases how fast you farm coins, cells and other resources.

Description
The Game Speed upgrade raises the cap on how fast the game can run. You can then select higher speed multipliers during a round, compressing more game time into each minute of real time.
Rounds
Game speed affects the pace of the whole round, and it shows up in several places. On the stats screen, real time and game time will not match, because game time runs faster at higher multipliers. Any ability that works on a timer is also sped up by game speed, so cooldowns and durations pass quicker in real terms.
With the Game Speed perk taken during a round and the Standard Perk Bonus lab researched, game speed reaches a maximum of 6.25x, which the game displays as 6.3x. Note that the displayed multiplier is not fully accurate: 5.0x behaves closer to 4.0x in practice, and 6.25x is closer to 5x.
Lab
The Game Speed lab is unlocked through Milestones at tier 1 wave 30. It has a maximum of 7 levels, and each level raises the game speed cap further. See the table below for the cost and effect of each level.
