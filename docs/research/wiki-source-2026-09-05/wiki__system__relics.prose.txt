Description
Relics are passive buffs to increase tower abilities. They sit alongside your other upgrades as a permanent boost, applying to every run without any input from you.
Unlock
You can browse relic unlocks in the Themes Menu. There are six main ways to earn them: reaching wave 4500 milestones, placing in tournaments, completing events and buying from the event store, the guild store, rewards for years of gameplay, and a gift commemorating the game's 5th Anniversary. Note that relics bought from the event store are only available when that event is re-run, so if you miss one you will need to wait for it to come back.
Using Relics
